# AEO God Mode — Competitor Analysis & AEOmatic Action Plan

Source: Full site audit of aeogodmode.io (June 2026)

---

## What God Mode Does Well (that AEOmatic should match or beat)

- Hero heading is clear and differentiated: "Optimize for AI Search. Not just Google."
- Stats section cites real sources (Semrush, BrightEdge) — adds credibility
- Comparison table (Yoast vs AEO God Mode) is a strong differentiator and conversion tool
- Pricing shown on homepage — removes a click from the conversion path
- Full feature sub-pages (Citation Tracker, E-E-A-T Schema, Content Gap Scanner, etc.) each with their own SEO-targeted title
- Documentation is extensive with clear category groupings
- "Free AI Search Audit" lead-gen tool exists (though buried)

---

## God Mode's Weaknesses (AEOmatic's opportunities)

| Weakness | AEOmatic Opportunity |
|---|---|
| Blog is JavaScript-rendered (Google can't index it) | Serve blog content server-side from day one |
| Only ~1 visible blog post (very thin) | Publish 20–30 posts to own the AEO topic cluster |
| No About page (E-E-A-T gap) | Add About/team page with author credentials |
| FAQ answers hidden in JS accordion (Google may miss them) | Keep FAQ answers in DOM always; add FAQPage schema |
| Case Studies links off-site to metronyxai.com (leaks authority) | Keep all case studies on aeomatic domain |
| Nav "Pro Features" listed twice — confusing | Keep nav clean and clear |
| 1-star public review on pricing page, unaddressed | Actively respond to all reviews |
| Currency in GBP only — confuses global buyers | AEOmatic is free — no pricing friction at all |
| Feature pages lack breadcrumb navigation (ironic for a schema plugin) | Add breadcrumbs to any future feature pages |
| Feature CTAs use generic "Learn more →" anchor text | Use descriptive CTA text: "Explore schema detection →" |
| Plugin itself has no schema on its own homepage (ironic) | AEOmatic homepage should demonstrate FAQPage + SoftwareApplication schema |
| "Free AI Audit" tool is buried in footer | Make the plugin download the primary hero CTA |

## AEOmatic Action Plan — Prioritised

- [x] FAQPage JSON-LD schema for the FAQ section
- [x] SoftwareApplication JSON-LD schema (price, rating, features)
- [x] Organization JSON-LD schema
- [x] Title tag: "AEOmatic — Free WordPress AEO Plugin | Get Cited by ChatGPT, Claude & Gemini"

- [x] Blog preview section: 3 article cards to establish topical authority + add #blog to nav
- [x] E-E-A-T / About signal: add brief "Built in the open" credibility note

### Tier 2: Build pages next

- [ ] `/blog/` — Start with 5 posts; target these exact keywords:
  - "what is llms.txt wordpress" (very low competition)

  - "aeo vs seo difference 2026"

- [ ] `/features/` — dedicated features overview page (God Mode has /plugin/)
- [ ] `/pricing/` — even though free, a pricing page comparing AEOmatic vs paid alternatives ranks on "[tool] pricing" queries
- [ ] `/about/` — team page with author bios, credentials, E-E-A-T signals

### Tier 3: Ongoing

- [ ] Respond to all WordPress.org reviews within 48 hours

## Structural Gaps vs God Mode

God Mode has these pages/sections that AEOmatic currently lacks:
- Dedicated `/plugin/` overview page with full feature list
- Individual feature pages (each rankable on their own keyword)
- `/docs/` documentation hub
- `/blog/` with category/tag filtering and author bylines
- "As Featured In" press logos section
- "Free AI Search Audit" lead-gen tool
- Case studies / success stories
- Agency/reseller pricing tier
